# 화면 캡처 블루

Screen-focused Authored style inspired by the visual composition of the user-provided
Samsung_Display_AX_Proposal_28p_Aligned_Final.pptx (28 image-only 16:9 pages).
Colors and typography are visual approximations, not extracted font/theme metadata.

The five HTML sources are the editable design sources for the matching PNG references.
All example application screens and copy were authored for this style and explicitly
labeled illustrative. No original deck pixels, personal records, client logos or
performance claims are distributed with this preset. Reference images guide composition;
actual generation must use the current user's bound screenshot assets.

The catalogue preview is workflow.png. Content references demonstrate a large single
screen and a paired comparison; the timeline reference demonstrates three steps.
The prompt exemplar is ../../authored_styles/exemplars/screenshot-blue.html and remains
below the 12,000-character loader limit. Its sample UI is a compact SVG illustration,
not a prescription to redraw a user's screenshots.

To refresh PNGs, render the matching local HTML in Chromium at 1280x720, device scale 1,
after local Korean fonts have loaded. There are no remote assets or scripts.
