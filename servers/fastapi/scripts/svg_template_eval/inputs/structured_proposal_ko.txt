## 한빛정밀 제조 ERP 현대화 사업 제안서
한빛정밀(가상의 중견 제조사)의 20년 된 온프레미스 ERP를 클라우드 기반 통합 업무 플랫폼으로 전환하는 사업의 제안서이다. 이 문서의 회사와 수치는 평가용으로 만든 가상의 자료이다.
사업 기간은 2027년 3월부터 2028년 2월까지 12개월이며 총 사업비는 38억 원이다. 대상 업무는 생산, 구매, 재고, 영업, 회계 5개 영역이다.

## 사업 배경과 현황
현행 시스템은 2007년에 도입했고 업무 영역별로 따로 구축되어 있다.
- 영역 간 데이터를 월 마감 때 엑셀로 옮겨서 대조하며, 이 작업에 월평균 6일이 든다.
- 재고 정보가 하루 한 번 갱신되어 현장 재고와 시스템 재고의 오차율이 4.2퍼센트이다.
- 장애는 연평균 14건이며 복구까지 평균 5.5시간이 걸린다.
- 유지보수 계약 종료가 2027년 12월이라 이전 시점이 정해져 있다.

| 구분 | 현재 | 목표 |
| --- | --- | --- |
| 월 마감 소요 | 6일 | 2일 |
| 재고 오차율 | 4.2% | 1.0% 이하 |
| 연간 장애 건수 | 14건 | 4건 이하 |
| 평균 복구 시간 | 5.5시간 | 1시간 이내 |

## 전환 접근 방식
전환은 다섯 단계를 순서대로 진행한다. 앞 단계의 승인이 있어야 다음 단계를 시작한다.
1단계 현황 분석: 업무와 데이터 흐름을 조사한다. 이 단계가 끝나면 2단계 설계로 넘어간다.
2단계 표준 설계: 공통 코드와 데이터 모델을 정의한다. 설계 승인 후 3단계 구축을 시작한다.
3단계 구축과 이관: 영역별로 개발하고 데이터를 옮긴다. 시험을 통과하면 4단계로 간다.
4단계 통합 시험: 영역 간 연계와 성능을 검증한다. 합격하면 5단계로 이어진다.
5단계 안정화: 병행 운영을 거쳐 기존 시스템을 종료한다.

## 시스템 구조
플랫폼은 네 개 계층으로 구성한다. 위 계층이 바로 아래 계층만 호출한다.
- 사용자 계층: 웹 포털, 모바일 앱, 현장 단말
- 업무 서비스 계층: 생산, 구매, 재고, 영업, 회계 모듈
- 공통 플랫폼 계층: 인증, 코드 관리, 워크플로, 알림, 보고서
- 인프라 계층: 클라우드 컨테이너 환경, 데이터베이스, 백업, 모니터링

## 수행 일정
| 단계 | 기간 | 주요 산출물 |
| --- | --- | --- |
| 현황 분석 | 2027년 3월~4월 | 업무 분석서, 데이터 정의서 |
| 표준 설계 | 2027년 5월~6월 | 아키텍처 설계서, 코드 체계 |
| 구축과 이관 | 2027년 7월~11월 | 모듈별 소스, 이관 결과서 |
| 통합 시험 | 2027년 12월~2028년 1월 | 시험 결과서, 성능 보고서 |
| 안정화 | 2028년 2월 | 인수인계서, 운영 매뉴얼 |

## 투입 인력과 역할
총 22명이 참여하며 최대 투입 시점은 구축 단계의 18명이다.
| 역할 | 인원 | 주요 업무 |
| --- | --- | --- |
| 프로젝트 관리자 | 1명 | 일정, 품질, 위험 관리 |
| 업무 분석가 | 4명 | 요구사항 정의, 업무 설계 |
| 아키텍트 | 2명 | 구조 설계, 기술 표준 |
| 개발자 | 10명 | 모듈 개발, 연계 구현 |
| 시험 담당 | 3명 | 시험 계획, 결함 관리 |
| 이관 담당 | 2명 | 데이터 정제, 이관 검증 |

## 데이터 이관 절차
이관은 네 번에 나누어 실행한다. 1차 이관은 기준정보(품목, 거래처)이고, 2차는 재고와 구매, 3차는 생산과 영업, 4차는 회계이다.
각 차수는 같은 순서로 진행한다. 추출, 정제, 적재, 검증, 승인의 다섯 활동을 거치며 검증에서 불일치율이 0.1퍼센트를 넘으면 정제 활동으로 돌아간다.

## 위험 관리
| 위험 | 가능성 | 대응 |
| --- | --- | --- |
| 이관 데이터 품질 저하 | 높음 | 차수별 검증 기준과 정제 전담 인력 |
| 현업 일정 충돌 | 중간 | 월 마감 주간에는 시험 제외 |
| 외부 시스템 연계 지연 | 중간 | 연계 담당자를 사전에 지정하고 모의 시험 선행 |
| 사용자 적응 지연 | 낮음 | 부서별 교육 3회와 현장 지원 2주 |

## 운영과 유지보수
안정화 이후 12개월은 하자보수 기간이다. 장애 등급은 4단계이며 1등급은 서비스 중단, 2등급은 주요 기능 장애이다.
응답 목표는 1등급 30분 이내 착수, 2등급 2시간 이내 착수이고 가용성 목표는 연 99.5퍼센트이다. 정기 점검은 월 1회 시행한다.

## 기대 효과
월 마감 소요를 6일에서 2일로 줄이고 재고 오차율을 4.2퍼센트에서 1.0퍼센트 이하로 낮춘다. 연간 장애 건수는 14건에서 4건 이하로, 평균 복구 시간은 5.5시간에서 1시간 이내로 줄이는 것이 목표이다.
이 목표는 안정화 종료 시점의 측정값으로 확인하고 결과를 발주기관에 보고한다.
