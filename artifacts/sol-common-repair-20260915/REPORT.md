# Sol medium 공통 보정·프롬프트 시험 최종 보고서

**상태: 시험·독립 감사·최종 재판정 완료.** 변경 모듈 최종 검사는34개 통과·1개 기존 실패다. 이번 수정으로 발생했던 과거 경계 사례4건의 검출 회귀는 수정했고, 남은1건은 변경 전 HEAD의 category 목록과 테스트 기대값 불일치임을 소스로 확인했다. 전체 테스트 통과라고 보고하지 않는다.

## 결론

공통 배치 결함 한 종류는 실제 제품 fitter에서 해결했다. 그러나 새 프롬프트는 정상 대조군에서 이미지와 배치가 퇴행해 채택하지 않는다. 승인된 초기 생성 12회와 독립 감사 24개를 모두 완료했으며 추가 반복, 신규 문서 10페이지, PPTX 내보내기로 진출하지 않는다.

제품 코드 변경은 작업 폴더에 있으며 이번 작업에서 서버 재시작·실행 중 서비스 반영·배포는 하지 않았다. 아래 제품 검증은 공통 렌더러/fitter를 직접 호출한 실제 실행이며 UI 생성·큐·PPTX 내보내기 전체 경로 검증은 아니다.

## 프롬프트와 보정 효과

같은 원본 6페이지에서 기존/개선 프롬프트로 각각 한 번씩 생성했다. 각 생성 HTML 하나를 보정 off/on에 공유했다. 24개 결과는 서로 다른 문서 24개가 아니다. 내용 통과는 요구된 사실·조건·관계·이미지의 실제 가시성 보존을 포함한다. 시각 통과는 배치뿐 아니라 지정 이미지 처리·가독성·스타일을 포함하므로 배치 통과와 다를 수 있다.

| 프롬프트 | 공통 보정 | 내용 통과 | 배치 통과 | 시각 통과 | 내용·시각 통합 통과 |
|---|---|---:|---:|---:|---:|
| 기존 | off | 2/6 | 4/6 | 3/6 | 2/6 |
| 기존 | on | 2/6 | 4/6 | 3/6 | 2/6 |
| 개선 | off | 4/6 | 4/6 | 3/6 | 2/6 |
| 개선 | on | 4/6 | 5/6 | 4/6 | 3/6 |

최초 생성끼리 비교하면 개선 프롬프트는 sol-p02를 개선했지만 astra-p19를 악화시켜 통합 통과 순증가는0이다. 보정 on끼리는 sol-p02와 sol-p28에서 개선, astra-p19에서 악화하여 순증가1이다. 동일 생성 HTML의 보정 효과는 기존 프롬프트에서 추가 통합 통과0, 개선 프롬프트에서 sol-p28 한 개 증가다. 프롬프트 효과와 후처리 효과를 합쳐 최초 생성 개선이라고 보고하지 않는다.

정상 대조군 astra-p19는 기존 프롬프트에서 타깃의 모든 동심원이 보이고 내용·시각이 통과했지만 개선 프롬프트 off/on 모두 타깃이 보이지 않고 카드 탈출이 발생했다. 가독성/스타일도 각각2→1로 낮아졌다. 따라서 aggregate 통과 증가와 무관하게 동결한 정상 대조군 무퇴행 기준을 위반했다.

다른 정상 대조군 sol-p06은 기존 프롬프트에서 업무담당자 통합 조회의 성과정보를 누락했고 개선 프롬프트에서는 서류정보를 누락했다. 양쪽 모두 내용 실패라는 boolean만으로 새 누락 종류를 숨기지 않았다. 보정 뒤 DOM문자가 같다는 이유로 원래 내용 실패를 통과로 승격하지 않았다.

## 실제 공통 코드 수정

1. `servers/fastapi/utils/authored_dom_text_escape.py`: 텍스트의 가장 가까운 내부 카드만 보던 검사를 위반한 상위 카드까지 확장했다. 명시적인 intentional/decoration 예외를 유지한다.
2. `servers/fastapi/utils/slide_capture_fit_geometry.py`: 내부 측정 문제만 사라지고 외부 카드 탈출이 남는 보정 후보를 실제 상위 카드 containment 기준에서 거부한다. 기존 보정 검색을 재사용한다.
3. `servers/fastapi/tests/unit/test_authored_dom_text_escape.py`: 중첩 경계와 명시적 배지 예외를 확인한다.

대표 원인은 높이137px grid 안의 내부 카드가 min-height:auto와 내용량 때문에186px로 확장된 것이다. 글자는 내부 카드 안에 있어도 외부 카드 밖으로 나왔다. 수정 전 검사기는 이를 놓쳤다. 저장 결과18개 재판정에서 해당 실패1개가 추가 검출됐고 기존 배치 정상5개는 그대로 통과했다. 검출 증가 자체를 PPT 품질 개선으로 계산하지 않는다.

기존 결과 중 실패8개·정상2개를 고른 대표10개의 실제 제품 fitter 검증에서는1개를 완전히 해결하고1개를 부분 개선했다. 정상2개는 원본 HTML을 유지했다. 완전히 해결한 결과는 독립 시각 검수에서도 통과했다. 해당 결과의 본문14px 한 항목을13.3px로5% 축소했으며 이는 기존9pt 하한과 최대10% 축소 정책 안이다. artifact의 별도 간격 후보는 글자 크기를 유지했지만 실제 제품 검색의 선택은 달랐다.

부분 개선된 case06은 자동 blocker0이어도 기존 설명 가림이 남아 전체 품질 실패로 유지했다. 정상 case10도 시각적으로 동일하지만 기존 fit 정책은 font_unverifiable/unresolved를 반환했다. 자동 검사, fit 정책, 독립 품질은 별도로 기록했다.

## 속도와 호출

이번 초기 프롬프트 시험은 gpt-5.6-sol / medium 요청12회가 모두 성공했고 실행 중 호출은0이다. 사용량/전송 영수증은12개 모두 확보했다. 제공자가 실제 실행 모델 식별자를 반환하지 않아 요청 모델과 추론 강도까지만 확인했다.

| 실제 측정 항목 | 12회 관측 중앙값 |
|---|---:|
| 모델 생성 요청 | 93.13초 |
| 보정 off 렌더 | 2.93초 |
| 보정 off 검사 | 0.08초 |
| 보정 on 추가 처리 | 4.29초 |
| 한 생성의 off와 on을 순서대로 마친 실험 전체 | 100.82초 |

마지막 행은 실제 단조시계 실험 시간이며 사용자 서비스의 단일 생성 완료시간이 아니다. 공유한 생성과 두 분기를 합친 실험이므로 on/off의 독립 서비스 전체시간처럼 해석하지 않는다. 중앙값끼리 더해서 전체시간을 만들지 않았다. on의4.29초는 보정 시도·렌더·필요한 재캡처·검사 비용이며 순수 보정 알고리즘 시간만은 아니다.

프롬프트별 실제 측정 중앙값도 분리했다.

| 항목 | 기존 프롬프트 | 개선 프롬프트 |
|---|---:|---:|
| provider 응답 | 103.51초 | 85.34초 |
| 공유 생성 시작→off 검사 완료 | 107.08초 | 89.29초 |
| on 추가 처리 | 4.20초 | 4.29초 |

개선 프롬프트의 생성 단계는 이번 관측에서 빨랐지만 정상 대조군의 품질 퇴행을 상쇄하지 않는다. 공유 생성→off 검사는 실제 측정한 실험 구간이고 서비스 전체 지연시간이 아니다.

실제 캡처는26회(off12 + on fit12 + 변경 HTML 재캡처2)였다. on의 fit 상태는 spacing_adjusted2, unchanged2, unresolved8이다. 부분/미해결 정책 상태를 품질 통과로 계산하지 않는다. 이번 후보는 품질 퇴행으로 이미 gate를 위반했으므로 공유 단계 합산 추정시간으로 속도 우위를 주장하거나 추가 반복을 허용하지 않는다.

## 검증 근거와 한계

최종 독립 감사24개를 모두 결합했고 각 HTML/PNG 해시를 확인했다. 24개 패킷의 전체 sourceContent는 기존 동결 원문 해시와 일치하며 필수 이미지 assignment/candidate와 원본 이미지 파일 해시도 확인했다. 내용/시각 감사는 생성·수정과 분리해 진행했다. 원래 source에서 요구하지 않은 p25 이미지 내 세부 글자 가독성을 사후 기준으로 추가한 판정은 제거했으며, p17은 source에 작은 글자 보존 요구가 명시돼 partial을 유지했다. 이를 소급해서 모델 입력을 고치는 피드백으로 사용하지 않았다.

검증 이력에는 좁은 detector 테스트2개 통과, 저장18개 재판정, 실제 제품10개 렌더, 새 생성12회 및 off/on24개 독립 감사가 포함된다. 최종 모듈 검사에서 처음30개 통과·5개 실패가 확인됐고, 그중 이번 ancestor 예외 처리로 발생한 과거 run29 사례4건 회귀를 수정한 후34개 통과·1개 실패가 됐다. 남은 category 테스트 함수와 관련 registry/empty-media 모듈은 HEAD와 동일하며, 기존 exact-set 기대값이 empty_media_panel을 빠뜨린 불일치다. 요청과 무관한 category 계약은 변경하지 않았다. 최종 detector로 저장24개를 다시 검사해 자동 판정 및 blocker(category,qids) 변화0을 확인했고 원자료 HTML/PNG는 모두 불변이다. 유료 생성 때의 detector와 최종 detector는 버전이 다르지만, 실제 생성 결과·독립 품질 판정·공통 fitter geometry 버전은 바뀌지 않았다. 초기 synthetic browser fixture는 적절하지 않아1회 실패 후 제거했고, 그 실패를 제품 회귀 증거로 사용하지 않았다. 초기 직접 fit 호출의 QID 준비 누락과 B source metadata 상속 누락은 실행부 문제로 분리하고 원본을 보존해 복구했다. 현재 통과한 제품 실행은 완전 QID 준비와 변경 HTML의 fit-disabled 재캡처를 거친 결과다.

소규모 고정6개 입력의 한 번 생성 비교다. 반복 안정성, 신규 문서 일반화, 전체 서비스 속도, PPTX 내보내기 품질은 이번 결과로 입증하지 않았다. 원래 프롬프트는 유지하고 새 보조 프롬프트는 실험 파일로만 남긴다. 공통 코드 수정의 적용 가능성과 프롬프트 채택 여부를 분리한다.
