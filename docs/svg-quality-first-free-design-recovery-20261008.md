# SVG 자유 설계와 품질 복구

품질을 최우선, 최종 완료까지의 생성 속도를 두 번째 목표로 둔다. LLM이 페이지 전체를 설계하는 기존 SVG 생성 경로를 유지하되 첫 작성부터 충분한 디자인 자료를 제공해 재작성 필요성을 줄인다. 실제 결과의 디자인과 화면 안정성을 검사한 뒤, 디자인이 부족한 페이지는 자유롭게 다시 작성하고 화면이 깨진 페이지는 국소 수정한다. 국소 수정으로 해결하지 못한 페이지만 검증된 SVG를 바탕으로 대체한다. 대체 구성의 반복도 검사하며 원본 내용과 편집성을 유지한 결과만 완료로 판정한다.

속도는 첫 미리보기 표시까지가 아니라 필수 검사와 PPTX 내보내기를 통과한 최종 결과까지의 시간으로 판단한다. 품질 기준을 충족한 처리 방식 중 불필요한 호출·재검사·대기를 줄이는 방식을 선택한다. 검사를 생략하거나 낮은 품질의 결과를 먼저 완료로 표시하는 방식은 속도 개선으로 인정하지 않는다.

이 설계는 기존 자유 생성 설계의 일반 작성 원칙을 유지한다. 대체 구성은 이번에 사용자가 승인한 화면 깨짐 복구 수단으로 한정한다. `svg-free-design-quality-recovery-design-20261002.md`의 과거 구현·실험 기록은 수정하지 않는다.

## 사용자 결정과 구현 범위

| 구분 | 결정 |
| --- | --- |
| 최우선 목표 | 이전에 잘 나온 결과 수준의 디자인, 가독성, 내용 충실도, PPTX 편집성을 확보한다. |
| 두 번째 목표 | 필수 품질을 유지하면서 최종 완료 시간을 줄인다. 첫 작성 개선, 선택적 수정, 검증 재사용, 기존 한도 내 병렬 처리를 우선한다. |
| 기본 작성 | 원본과 충분한 디자인 자료를 받은 LLM이 페이지 전체 SVG를 작성한다. |
| 디자인 문제 | 화면이 정상이어도 강조·위계·구성·반복 문제가 있으면 디자인 재작성 대상으로 삼는다. |
| 화면 문제 | 구문 오류, 겹침, 잘림, 화면 이탈, 가독성 실패를 구분하고 먼저 필요한 영역을 수정한다. |
| 대체 구성 | 화면 문제가 해결되지 않은 페이지에만 적용하며, 내용에 맞는 검증된 후보 중에서 선택한다. |
| 반복 방지 | 이름뿐 아니라 실제 배치와 읽는 흐름을 검사한다. 의도적인 비교·연속 자료의 반복은 허용한다. |
| 결과 선택 | 최신 작성 결과라는 이유로 채택하지 않는다. 현재 입력에서 유효한 이전 후보를 보존하고, 개선이 확인된 결과를 선택한다. |
| 금지 범위 | Deck-IR 신설·확장, 새 레이아웃 엔진, 좌표를 담은 별도 중간 표현, 일반 생성의 고정 패턴 순환을 추가하지 않는다. |
| 기존 작업 | 기존 작성 프로파일, 요청, 원본, 모델·비용 기록, 체크포인트, 실패·UNKNOWN 이력을 변경하지 않는다. |

페이지 유형이나 선택 후보를 코드로 나열하는 것만으로 품질을 달성했다고 판단하지 않는다. LLM 작성 지침, 참고자료, 실제 렌더 결과를 함께 개선한다. 이 설계에는 새 v9 작성 프로파일을 전제하지 않는다.

구현 위치는 기존 SVG 작성·렌더·품질·종료 처리 모듈이다. DB 테이블과 공개 작업 상태를 추가하지 않는다. 정책·검사·대체 선택 기록은 기존 요청 고정과 SVG 체크포인트·품질 영수증을 확장하는 범위에서 다룬다.

확인한 70장 결과는 참고 역할이 본문 69장, 구조도 1장이었다. 이 분포는 획일화 위험의 근거이며, 모든 페이지가 시각적으로 동일하다는 단독 증거는 아니다. 기존 v7 성공본과의 비교는 입력 자료·장수·캔버스가 달랐으므로 v8만의 영향으로 확정하지 않는다.

현재 스타일 참고 PNG를 곧바로 검증된 대체 레이아웃으로 취급하지 않는다. 새 내용과 목표 캔버스에서 작성·렌더·원본 보존·PPTX 편집성을 확인한 후보만 자동 대체에 사용한다.

## 전체 처리 순서

1. 원본 내용·수치·표·차트·이미지 그룹과 사용자가 선택한 출력 캔버스를 고정한다.
2. 선택한 템플릿의 디자인 지침, 좋은 결과 예시, 페이지의 핵심 메시지와 전후 맥락을 LLM에 전달한다.
3. LLM이 전체 페이지 SVG를 작성한다. 기존 동시 작성 경로를 유지한다.
4. 작성이 끝난 페이지부터 구문·렌더·원본 보존·가독성·기하 검사를 수행한다. 다른 페이지의 작성 완료를 기다릴 필요가 없는 검사를 먼저 처리한다.
5. 렌더가 준비된 페이지를 충분한 해상도의 묶음으로 디자인 리뷰한다. 덱 전체가 준비되면 전역 반복과 흐름을 평가한다.
6. 부족한 페이지에 필요한 수정만 수행한다. 전체 구도 결함은 자유 재작성으로, 국소 화면 문제는 관련 영역 수정으로 처리한다.
7. 화면 문제가 해소되지 않은 페이지만 적합한 검증 SVG를 바탕으로 필요한 부분을 수정한다.
8. 변경한 페이지를 재렌더하고 검사한 뒤 이전 유효 후보와 비교해 채택한다. 덱 반복·문맥 변화의 영향을 받는 판단도 갱신한다.
9. 최종 선택한 결과의 내보내기와 모든 필수 검사가 완료되고 통과한 경우에만 완료 결과를 전달한다. 미평가·근거 부족·복구 실패는 검토 필요 또는 기존 실패 경로로 남긴다.

위 단계는 내부 품질 처리 단계이며 공개 작업 상태 이름을 새로 정의하지 않는다. 예산·권한·기한·소비자 소유권 실패는 디자인 실패와 구분한다.

| 현재 판정 | 다음 처리 | 대체 구성 허용 |
| --- | --- | --- |
| 필수 내용과 화면이 정상이며 디자인도 충분함 | 현재 SVG를 유지한다. | 아니오 |
| 화면은 정상이나 디자인·불필요한 반복이 미달 | 원본을 유지하며 LLM이 전체 페이지를 다시 설계한다. | 아니오 |

| 평가 근거·적합 후보가 부족하거나 호출 한도가 소진됨 | 기존 작업 계약에 따라 미평가·검토 필요·실패를 처리한다. | 자동 통과하지 않음 |
| 권한·소유권·예산·기한·UNKNOWN 문제가 있음 | 추가 호출과 자동 복구를 중단한다. | 아니오 |

한 페이지에 여러 문제가 함께 있으면 결함의 범위를 함께 판단한다. 전체 구도를 다시 작성해야 하는 페이지에 국소 수정과 전체 재작성을 기계적으로 연속 수행하지 않는다. 어느 수정 방식을 선택하든 화면 오류를 해소한 실제 렌더로 디자인을 평가한다. 대체 작성이 화면 검사만 통과해도 디자인 검사가 미달이면 완료로 처리하지 않는다.

## LLM 작성 입력

### 원본과 디자인 자료

원본에는 페이지별 사실, 수치·단위, 설명 순서, 표·차트 바인딩, 이미지 그룹, 필수 보존 여부를 포함한다. 디자인 자료에는 팔레트·서체뿐 아니라 제목 위계, 강조 원칙, 이미지 처리, 정보 배치의 의도와 해당 스타일의 대표 표현을 포함한다.

이전에 잘 나온 페이지는 디자인 예시로 제공할 수 있다. 그 페이지의 제목·수치·회사명·주장은 현재 원본으로 취급하지 않는다. 참고자료의 기하가 새 캔버스에 적합한지는 별도로 판단한다.

첫 작성의 참고자료는 본문 역할의 예시 하나로 제한하지 않는다. 내용의 핵심 메시지·비교·순서·이미지 설명에 맞는 서로 다른 표현 예시를 골라 충분한 위계와 강조 방향을 전달한다. 페이지마다 고정 패턴을 배정하거나 표현을 순서대로 순환시키지 않는다. 기존 페이지 목적과 원본 맥락을 활용하며 별도 덱 계획이나 좌표 중간 표현을 만들지 않는다.

공통 스타일 자료는 고정된 참조와 해시로 재사용하고, 페이지별 입력에는 필요한 원본과 전후 맥락을 제공한다. 전체 덱의 SVG와 무관한 예시를 모든 호출에 반복 삽입하지 않는다. 필수 내용·이미지 그룹·디자인 원칙은 입력 절감 대상에서 제외한다. 모델의 문맥 한도에 맞추기 위해 원본을 누락하거나 이미지 개수를 임의로 제한하지 않는다.

### 작성 책임

일반 생성에서 좌표, 카드 수, 열 수, 패널 크기, 도형 배치와 표현 방식은 LLM이 결정한다. 설명·비교·순서·수치·관계를 읽기 좋게 구성하며, 원본에 없는 주장·날짜·값·관계를 추가하지 않는다.

템플릿의 브랜드와 시각적 위계는 유지해야 하는 요구로 전달한다. 위치·크기와 표현은 내용과 출력 캔버스에 맞게 조정한다. 전후 페이지는 덱의 흐름을 위한 맥락이며 내용을 이동하거나 생략할 권한으로 취급하지 않는다.

### 전체 재작성과 국소 수정

디자인 재작성에는 이전 렌더와 SVG, 원본, 선택한 스타일 예시, 구체적인 디자인 결함을 제공한다. 내용과 바인딩은 유지하되 전체 구도를 바꿀 수 있게 한다. 이를 기존의 국소 오류 보정 지침과 섞지 않는다.

국소 수정에는 측정된 충돌·잘림·기하 근거와 원본 SVG를 제공한다. 영향을 받는 라벨·관련 객체를 함께 조정하고 정상 영역의 구성과 브랜드 표현을 유지한다. 두 작업 모두 기존 작성 함수를 사용하며 별도의 작성 엔진을 만들지 않는다.

### 수정 전후 결과 선택

현재 입력과 정책에서 유효한 후보의 SVG·PNG·원본 바인딩과 검사 근거를 보존한다. 기존 아티팩트 참조와 해시를 재사용해 전체 내용을 체크포인트마다 중복 저장하지 않는다. 새 후보가 생겨도 이전 후보의 증거를 덮어쓰지 않고, 실제 선택을 기존 체크포인트에 별도로 기록한다. 오래된 부모 작업이나 고정된 요청을 재분류하는 수단으로 사용하지 않는다.

필수 내용·화면·가독성과 내보내기 구조 계약을 만족하는 후보만 선택 대상으로 삼는다. 디자인 재작성은 목표 결함이 개선되고 다른 필수 디자인 축에 중대한 퇴보가 없는지 비교한다. 국소 수정은 목표 오류가 해소되고 정상 영역의 구성이 유지되는지 확인한다. 재작성 결과가 더 나쁘거나 개선이 불확실하면 이전 유효 후보를 유지하고 시도를 자동 반복하지 않는다.

중간 후보에는 네이티브 객체·바인딩·지원 요소 등 필요한 구조 검사를 적용한다. 모든 초안을 매번 전체 PPTX로 내보내지는 않는다. 실제 최종 PPTX는 선택이 끝난 결과로 만들고 출력 일치·내용·편집성을 확인한다. 중간 후보의 구조 검사 통과를 최종 PPTX 편집성 검증 완료로 표시하지 않는다.

이전 후보도 완료 기준에 미달하면 보존했다는 이유로 완료 처리하지 않는다. 예산 안에서 개선하거나 기존 미달·검토 필요 경로로 남긴다. 덱 문맥이나 반복 판단이 바뀌면 이전 후보에도 현재 문맥의 판정을 적용한다.

## 검증된 대체 구성

### 후보의 정의

대체 후보의 기본 자료는 선택한 스타일과 목표 캔버스에서 검증된 실제 SVG다. 기존 지침과 PNG는 그 SVG의 디자인 의도를 설명하는 보조 자료로 사용한다. 예시를 보고 처음부터 자유 작성하는 방식은 안정적인 화면 복구와 구분한다.

기존 작성 함수에 검증 SVG를 이전 SVG로 전달하고, 현재 원본에 맞춰 바꿔야 하는 텍스트·이미지·네이티브 표·차트와 관련 영역을 명시한다. 검증된 구도와 정상 영역은 유지한다. 예시의 제목·수치·데이터·이미지 바인딩은 현재 원본으로 교체하며 참고자료의 내용을 섞지 않는다. 정상 배치를 넓게 해체해야 수용 가능한 후보는 적합 후보에서 제외한다.

별도의 레이아웃 트리, 요소 좌표 중간 표현, 슬롯 컴파일러를 만들지 않는다. 일반 생성에 강제 적용하지 않으며, 내용 교체 후의 SVG는 새로운 결과로 다시 검사한다. 검증 SVG를 사용했다는 사실만으로 화면 안정성이나 원본 보존을 보장한다고 판단하지 않는다.

후보의 최소 관리 정보는 식별자·개정, 스타일 정체성, 적합한 내용과 캔버스, SVG·지침·예시의 참조와 해시, 검증 조건·결과다. 이를 기존 스타일 자료와 품질 영수증에서 관리한다. 참조 이미지 한 장이나 과거 테스트 성공만으로 모든 길이·이미지 수의 내용에 적합하다고 선언하지 않는다.

### 후보 적합성

스타일 정체성, 원본 보존 방식, 출력 캔버스와 내용 구조가 맞는 후보를 먼저 추린다. 이후 읽기 쉬운 정보 배치, 해당 내용량·이미지 그룹의 수용 가능성, 주변 페이지와의 관계를 비교한다.

예시 범주는 핵심 주장과 근거, 원본 수치 강조, 비교, 단계별 흐름, 실제 일정, 시스템 관계, 캡처 중심 설명, 긴 설명의 편집식 구성이다. 이 범주는 고정 패턴 순환표나 이미지 개수 제한이 아니다.

원본 재구성·고정 페이지 수·실제 시스템 요소 예약 등 필수 계약에 맞지 않는 후보는 제외한다. 현재 경로가 대체를 금지하는 모드에서는 해당 제한을 유지한다. 적합한 후보가 없으면 다른 양식을 억지로 채우지 않고 검토 필요로 남긴다.

## 대체 구성의 반복 방지

### 선택 순서

먼저 원본·스타일·캔버스 적합성과 가독성·디자인 기준을 충족한 후보군을 만든다. 품질 차이가 허용 가능한 범위 안의 후보끼리 실제 구도 유사성과 최근 사용 빈도를 반영해 선택한다. 품질을 충족하지 못한 후보를 다양성 때문에 선택하지 않는다.

품질 점수가 조금 높다는 이유만으로 같은 후보를 항상 선택하는 순위 규칙은 사용하지 않는다. 허용 가능한 품질 차이와 다양성 반영 범위는 성공본 비교로 고정한다. 적합한 후보가 하나뿐인 상황은 후보가 여럿인 상황과 구분한다.

같은 후보가 최근 많이 사용됐거나 실제 구성이 주변과 유사하면 다른 적합한 후보를 먼저 검토한다. 후보 이름이 달라도 핵심 강조 위치·텍스트와 이미지 비중·박스 배치·읽는 흐름이 비슷하면 반복으로 관찰한다.

반복 관찰에는 자유 생성과 대체 생성 페이지를 모두 포함한다. 인접 페이지의 연속 반복뿐 아니라 덱 전체에서 한 구성 계열이 지나치게 우세한지도 확인한다. 대체 후보만 서로 다르게 선택해도 나머지 자유 생성 페이지가 같은 구도라면 반복 문제가 해결된 것으로 판단하지 않는다. 팔레트·서체·로고·공통 머리말의 일관성은 브랜드 유지로 구분하고, 내용 영역의 정보 구조와 강조 방식에 집중한다.

현재 구성 관찰의 근사 유사도는 반복 후보를 찾는 신호로 사용한다. 그 임계값을 미적 품질 통과 기준으로 승격하지 않는다. 우선순위 가중치·허용 반복 범위는 이전 성공본과 대표 실패 사례로 조정한 뒤 고정한다.

불필요한 반복 그룹에서는 잘 나온 대표 페이지를 유지하고 디자인이 부족하거나 주변과 구분이 필요한 페이지를 우선 개선한다. 그룹 전체를 자동 재작성하지 않는다. 이웃 비교와 덱 전체의 대표 구성 비교를 함께 사용해 멀리 떨어진 반복도 관찰하되, 매번 모든 페이지 쌍에 시각 리뷰 호출을 수행하지 않는다.

### 반복을 허용하는 근거

동일 지표·기간·필드를 비교하는 연속 자료나 원본의 같은 절차 구조는 구성을 유지하는 것이 읽기 좋을 수 있다. 단순히 비교라는 단어가 있거나 내용 유형이 같다는 이유만으로 전체 덱의 반복을 면제하지 않는다. 실제 비교·연속 관계의 근거와 리뷰 판단을 함께 기록한다.

후보가 하나뿐이면 다양성을 위한 부적합 후보를 만들지 않는다. 유일한 적합 후보를 사용할 수 있지만 반복과 디자인 검사를 생략하지 않는다. 반복 문제가 해소되지 않으면 추가 자유 재작성 또는 검토 필요로 처리한다.

### 동시 작성과 재개

동시 작성의 완료 순서가 대체 선택을 바꾸지 않도록 한다. 초기 작성은 병렬로 유지하고, 덱 관찰과 대체 선택은 페이지 인덱스 및 고정된 후보 개정·검사 증거를 기준으로 결정한다.

같은 수정 라운드의 후보 선택을 먼저 고정한 뒤, 선택된 페이지의 작성·렌더를 기존 동시성 한도 안에서 병렬 수행한다. 선택 순서를 고정하기 위해 제공자 응답을 페이지 순서대로 기다리지 않는다. 라운드 결과가 모이면 현재 실제 구성으로 덱 반복 판단을 갱신한다.

후보 선택 시점의 근거와 실제 선택을 기존 체크포인트에 저장한다. 재개 시 이미 선택한 후보를 다시 추첨하거나 변경하지 않는다. 스타일이나 후보의 전역 최신 상태로 과거 작업을 재해석하지 않는다.

## 품질을 유지하는 속도 개선

### 검사와 작성의 병렬 처리

페이지가 준비되는 대로 로컬 검사·렌더를 수행하고, 리뷰 입력이 준비된 묶음부터 디자인을 평가한다. 묶음 크기는 입력 한도와 실제 판독 해상도를 기준으로 정한다. 모든 페이지를 충분한 해상도로 평가하며, 작은 전체 접촉 시트만으로 개별 페이지 검사를 대신하지 않는다. 필요한 확대 이미지는 해당 결함의 확인에 사용한다.

전체 덱 반복과 전후 흐름은 덱이 준비된 뒤 판단한다. 전역 판단을 기다릴 필요가 없는 국소 오류 수정은 먼저 진행할 수 있다. 정상 페이지까지 같은 수정 라운드를 기다리거나 불필요하게 다시 작성하지 않는다. 최종 완료는 모든 필수 증거가 모인 뒤에만 가능하다.

기존 제공자·브라우저 동시성 및 호출 예산을 유지한다. 고정된 단계별 작업이 앞 단계 리뷰 통과 후 다음 단계를 시작하도록 정해져 있으면 그 경계를 넘겨 호출하지 않는다. 병렬화 때문에 권한·소유권 검사나 취소·UNKNOWN 처리가 늦어지지 않도록 한다.

### 변경 없는 결과의 재사용

검증 재사용은 같은 소유자·테넌트와 허용된 원본 참조 안에서 수행한다. 페이지 revision, 원본·SVG·PNG 해시, 캔버스, 스타일·참고자료, 작성·품질 정책, 검사 도구·폰트·렌더 조건이 일치하는 증거만 재사용한다. 현재 권한·소유권·기한은 재사용 전에 확인한다.

원본·SVG가 바뀐 페이지는 관련 검사와 렌더를 다시 수행한다. 주변 페이지나 덱 구성이 바뀌면 바이트가 그대로인 페이지라도 영향을 받는 흐름·반복 판정을 갱신한다. 로컬 보존·기하 검사와 덱 문맥 리뷰의 유효 범위를 구분해 필요한 부분만 다시 검사한다.

내보내기 결과는 최종 선택한 revision과 PPTX 해시에 연결한다. SVG의 검증 결과를 새 PPTX의 편집성·출력 일치 증거로 대신하지 않는다. 원본이 같다는 이유로 다른 작업의 완료 상태나 오래된 시각 리뷰를 자동 복사하지 않는다.

### 수정 횟수와 대기 줄이기

같은 페이지의 결함 중 한 번의 수정으로 해결 가능한 문제는 함께 전달한다. 명확한 개선 목표가 있는 페이지에만 추가 호출을 사용하고, 목표 결함이 그대로거나 결과가 번갈아 나빠지는 반복은 중단한다. 실패한 결과를 보존하고 다음 허용 복구 분기나 검토 필요로 처리한다.

첫 작성, 수정, 리뷰, 내보내기별 대기와 실행 시간을 구분한다. 호출 수 감소를 시간 감소로 환산하지 않으며, 최종 완료 시간의 병목을 기준으로 개선한다. 속도 때문에 모델의 품질 수준이나 필수 검사를 임의로 낮추지 않는다.

## 영수증과 작업 경계

기존 SVG 체크포인트에는 작성 원본·SVG·PNG 해시, 스타일과 요청 바인딩, 평가 완료 여부와 결함, 수정 종류, 선택한 대체 후보와 검증 개정, 수정 전후 선택 근거, 반복 판단, 검증 재사용 근거, 시도 기록을 남긴다. 요소 좌표·슬롯 구조를 담는 새로운 덱 중간 표현을 만들지 않는다.

새 정책은 새 요청에서 고정하고 요청·스타일 해시에 구분되게 반영한다. 고정된 정책이 없는 과거 작업은 기존 재개 계약을 유지한다. 공개 필드로 신뢰된 정책·검증 통과를 주입할 수 없게 한다. 기존 작업의 요청·원본·부모 영수증을 변경하지 않는다.

원본의 revision이나 SVG·PNG가 바뀌면 이전 평가·대체 적합성 증거를 무효로 처리한다. UNKNOWN, 소비자 소유권 상실, 권한·예산·기한 실패는 자동 재작성이나 다른 대체 후보 선택으로 우회하지 않는다.

사용자 화면에는 디자인 점검·일부 페이지 개선·검토 필요를 설명한다. 원시 프롬프트, 제공자 오류 본문, 자격 증명, 디버깅용 점수·정책 식별자를 결과 설명에 노출하지 않는다.

## 호출 예산과 반복 제한

전체 디자인 재작성, 국소 수정, 대체 재작성, 시각 리뷰는 각각 실제 제공자 호출을 사용할 수 있다. 기존 admission·예산·기한·idempotency·소비자 소유권 검증을 공통으로 적용한다. 디자이너 루프를 무제한으로 돌리지 않는다.

구현 단계와 무료 확인에서 새 제공자 호출을 하지 않는다. 실제 검증 전에는 생성·수정·리뷰의 계획 요청 수와 총 상한을 정한다. 먼저 대표 페이지 및 기존 12장과 같은 조건을 검증하고 결과에 따라 A4·70장 검증을 승인한다.

반복 수정은 부족한 페이지에만 적용한다. 상한을 소진한 페이지는 미달 또는 검토 필요로 남기며, 통과 표시나 원본·회계 상태 초기화로 마무리하지 않는다. 새 호출·한도 증가는 별도로 승인받는다.

## 구현 순서와 완료 조건

1. 이전 성공본, 같은 내용·스타일·캔버스, 대표 화면 오류 및 획일화 사례를 기준 자료로 고정한다.
2. 첫 작성의 디자인 지침과 참고 선택, 판정 기준, 수정 전후 결과 선택을 먼저 개선한다. 대표 페이지의 실제 품질을 확인한다.
3. 원본 보존·화면·디자인·반복 판정을 연결한다. 빈 리뷰와 해상도 부족은 평가 완료로 간주하지 않는다.
4. 적합성이 실제 검증된 복수 SVG 후보와 선택 기록을 준비하고, 화면 복구 단계에만 연결한다.
5. 기존 한도 내 병렬 검사·수정과 검증 재사용을 연결한다. 기존 작업 재개·후보 고정·예산 소진·UNKNOWN 중단도 직접 연결된 좁은 확인으로 검증한다.
6. 같은 조건의 실제 12장 비교에서 품질과 최종 완료 시간을 확인한 뒤 A4와 긴 덱의 반복·가독성·PPTX 편집성을 검증한다.

문서·구문·fixture·구조 검사 통과는 디자인 품질 복구 완료가 아니다. 실제 결과에서 이전 수준의 강조·위계·정보 구성·가독성과 내용·편집성이 확인돼야 완료다.

### 품질과 속도의 비교 기준

같은 모델·추론 설정·입력·스타일·캔버스·장수·동시성·품질 기준에서 비교한다. 품질 기준 충족 여부, 첫 작성 통과율, 최종 완료 시간, 단계별 실행·대기 시간, 수정·리뷰 호출 수, 입력·출력 토큰, 실패·미완료 건수를 함께 기록한다. 비교 중 기준을 낮추거나 실패 건을 제외해 빨라졌다고 판단하지 않는다.

반복 실행에서 중앙값과 지연이 큰 사례를 확인하고 표본 수를 함께 제시한다. 대표 한 번의 생성으로 전체 속도 개선을 확정하지 않는다. 품질이 유지·개선된 조건에서 최종 완료 시간과 불필요한 호출·대기가 줄어야 속도 개선으로 인정한다. 실제 검증 전의 설계 점수와 예상 개선율은 측정 성과로 사용하지 않는다.

## 구현 전에 고정할 제안

사용자가 승인한 품질 우선·속도 두 번째 목표, 처리 흐름과 금지 범위는 위 설계의 기준이다. 디자인 판정의 성공본 수준, 후보 간 허용 가능한 품질 차이, 반복 관찰의 판정 경계, 최초 검증 SVG·적용 범위, 리뷰 해상도·묶음 크기와 실제 호출 상한은 대표 결과로 확인한 뒤 고정한다. 현재 참고자료만으로 검증된 후보가 모두 준비됐다고 가정하지 않는다. 병렬화·증거 재사용의 세부 방식은 현재 작업 계약을 만족하는지 확인하며 구현한다.

표지·목차·출력 캔버스는 작성 프로파일과 별도 요청 설정이다. 이번 설계가 사용자의 선택을 임의로 바꾸거나, 원본 보존 모드에 새 페이지를 추가하지 않는다.
