## 새 정책의 활성화와 예산

자동 활성화 대상은 새 admission에서 고정하는 implicit-default SVG 요청이며, vision QA가 켜져 있고 출력이 2페이지 이상인 경우다. 명시적으로 선택한 기존 작성 프로파일, 과거 고정 스냅샷, 단계별 작업과 raster reconstruction은 기존 경로를 유지한다. source wrapper의 새 수정 인자 전달은 기존 whole-page 보존·native 검사와 대체 금지 계약 안에서만 사용한다.

품질 정책은 `svg-quality-first@1`, 작성 프로파일은 기존 `art-direction-v1@8`을 사용한다. 리뷰는 최대 두 단계이며 실제 물리 호출 계획을 스냅샷에 고정한다. 70페이지의 최대 리뷰 계획은 단계당 로컬 14회와 전역 1회, 총 30회다. 수정이 없거나 로컬 증거가 재사용되면 해당 후속 호출은 수행하지 않는다. 이는 계획 계산이며 실제 호출 수·처리 시간 측정값이 아니다.

일반·디자인 작성은 기존 두 번 범위에서 수행한다. 새 계획에서 검증된 후보를 예약한 알려진 화면 오류 복구만 선택적인 세 번째 적응을 허용한다. 과거 두 번 계획은 두 번으로 재개한다. 모든 실제 호출은 기존 부모 요청·retry·추정 비용·실제 비용의 원자 한도 검사를 통과해야 하며 전체 상한을 늘리지 않는다.

입출력은 기존 4,000 출력 토큰과 로컬 이미지·요청 바이트 범위 안에서 처리한다. 전역 설명은 공유 findings와 명시적인 전체 페이지 분할로 압축하며 표현할 수 없는 결함은 미평가로 차단한다. 로컬 입력 범위 확인은 제공자의 실제 문맥·이미지 용량을 증명하지 않는다.

## 남은 수용 검증

실제 검증된 전체 페이지 SVG 후보 등록은 **0개**다. 참고 PNG나 모티프 SVG를 검증된 복구 페이지로 승격하지 않았다. 복구 실행 경로는 실제 검증 자료가 등록되고 현재 조건·적합성·예산이 맞을 때만 사용할 수 있다.

이전 성공본 수준의 디자인 판정 보정, 실제 제공자의 묶음 리뷰 완결·용량, 원본 캡처 그룹 유지, 최종 PPTX의 편집성·출력 일치와 같은 조건의 생성 완료 시간은 확인하지 않았다. 새 정책 덱을 편집·재생성하면 기존 디자인 증거를 그대로 승격하지 않고 검토 필요로 남긴다. 편집 후 재검토의 제품 경로와 실제 수용 검증도 확인이 필요하다.

실제 비교는 승인된 원본·모델·스타일·캔버스·장수·동시성·품질 기준과 호출 상한을 고정한 뒤 진행한다. 실패·미완료 결과를 제외하거나 품질 기준을 낮춰 속도가 개선됐다고 판단하지 않는다.
