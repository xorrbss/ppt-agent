# Authored 겹침·공간 재배치 및 9pt 하한 설계

- 작성일: 2026-09-09
- 상태: 구현 전 설계안. 사용자 확정 사항은 최소 9pt 허용이며, 아래 알고리즘·지원 범위는 구현 제안이다.
- 제안 정책 revision: `authored-local-fit/v1.4`. 현재 제품 코드는 v1.3 / 9.5pt다.
- 선행 문서: [폰트·원본 보존](authored-local-fit-font-floor-design-20260908.md), [부모 영역 재배분](authored-local-fit-parent-reflow-design-20260908.md).
- 이번 산출물은 설계 문서다. 제품 코드 수정, 기존 발표 자료 변경, 생성·게시·내보내기는 후속 구현 범위다.

## 1. 목표와 결정

기존 HTML의 내용·디자인을 보존하면서 문제 영역의 글자 크기, 세로 간격, 카드 높이와 배치를 조정한다.
빈 공간이 있으면 그 공간을 후보에 반영하고, 글자 축소 후보와 비교한다. 전체 페이지 재저작 없이 처리한다.
7·14·16페이지를 보고 제기된 문제는 카드 내부 넘침뿐 아니라 형제 요소와 하단 고정 영역 사이의 겹침이다.
따라서 기존 후보 순서를 바꾸는 것과 함께, 보정 대상 감지 및 허용 배치 구조를 확장해야 한다.

### 사용자 확정

- 일반 Authored 국소 보정에서 최종 출력 기준 최소 9pt까지 축소를 허용한다.
- 9pt는 허용 하한이며 일괄 적용할 목표 크기가 아니다.

### 유지할 설계 기준

- 최대 축소율은 기존 원저작 대비 10%를 유지한다. 하한 변경을 축소율 제한 폐기로 해석하지 않는다.
- 결함이 있는 카드 안의 해당 텍스트 서식 그룹만 축소한다. 슬라이드 전체 또는 상위 컨테이너에 font-size/scale을 적용하지 않는다.
- 문자열, 수치, 일정의 가로 위치·기간, QID, DOM 순서, 이미지·폰트 자산 identity를 유지한다.
- 헤더·페이지 번호·보호 푸터 및 source-locked/exact-reconstruction의 보호 경계는 유지한다.
- 정상 페이지는 그대로 두고, 실패 시 원본 보존·페이지별 검토 표시 정책을 유지한다.

## 2. 확인된 실패와 설계상 의미

기준 실행은 `artifacts/authored-run49-exact-rerun-20260909/result.md`의 동일 문서 재실행이다.
직전 분석에서 원본 체크포인트·fit receipt와 저장된 브라우저 측정값을 확인했다. 아래 수치는 그 기록이며
이 설계 작성 중 새 렌더를 실행한 결과가 아니다. 사례별 이름·QID·좌표는 제품 분기 조건으로 사용하지 않는다.

측정된 가림 비율을 실제 글자 손실률로 해석하지 않으며, 경계 상자 교차와 실제 잉크/선/배경 교차를 구분한다.

## 3. 글자 크기 계약

```text
floor_pt = 9.0
minimum_allowed_pt = max(original_pt * 0.90, floor_pt)
```

| 원저작 크기 | 최저 허용 크기 | 최대 실제 축소 |
| --- | ---: | ---: |
| 12pt | 10.8pt | 10% |
| 10pt | 9pt | 10% |
| 9.75pt | 9pt | 약 7.69% |
| 9.5pt | 9pt | 약 5.26% |
| 9pt | 9pt | 0% |

원래 9pt 미만인 텍스트는 기존 하한 정상화 규칙에 따라 최소 9pt로 올린 뒤 수용 여부를 확인한다.
기준점은 최초 저작 revision의 run별 실제 크기다. 후보 재시도, 부모 확장, 체크포인트 재개로 재설정하지 않는다.
16페이지처럼 이미 보정한 HTML도 기존 baseline과 연결하며, `0.9 × 0.9`식 누적 축소를 금지한다.

최종 출력 크기는 출력 pt/렌더 CSS px 비율과 실제 텍스트 배율로 계산한다. 표준 0.75pt/px일 때 9pt는 12px다.
DPR을 글자 배율로 사용하지 않는다. 출력 정밀도에서 하한 아래로 내려가지 않도록 올림한다.
같은 서식 그룹은 같은 배율을 적용하고, 제목·본문·보조문구의 기존 위계 검사를 유지한다.

상수만 변경하면 충분하지 않다. `authored_local_fit_policy.py`의 `minimum_allowed_pt()`에 있는 Decimal 하한과
`authored_local_fit_evidence.py`의 오류 분류용 9.5 하드코딩도 공통 정책을 읽게 해야 한다.
브라우저 상수, author 프롬프트, 고정 슬롯, export/readback 소비자는 동일 정책을 받는다.
별도의 전역 composition/capability 정책을 이번 변경으로 일괄 완화하지 않는다. 중복 기준이 실제 대상에 적용되면
해당 소비 경계에서 local-fit 정책 적용 범위를 명시하며, 오류를 숨겨 통과시키지 않는다.

## 4. 승인 전 처리 흐름

```text
완전한 저작 HTML과 원본 baseline 확보
→ 카드 넘침 + 실제 형제/고정 영역 충돌 수집
→ 보호 경계 안에서 영향 영역과 사용 가능한 공간 결정
→ 공간·간격·폰트 및 제한된 조합 후보 생성
→ 동일 기준 상태에서 후보별 적용·측정·완전 복원
→ 통과 후보 선택 및 페이지 전체 충돌·보존 검사
→ 변경 HTML만 fit-disabled 독립 재렌더링·품질 검사
→ HTML·PNG·측정값·scene·receipt를 함께 확정
```

`authored_presentation_generation.py`의 승인된 local-fit 페이지 보존 분기는 유지한다.
경고 페이지를 자동 remake/repair 경로로 다시 넣지 않고, `authored_presentation_pipeline.py`의
`accept_*` 호출 전에 후보 탐색과 해당 품질 판정을 마친다. 승인 후 표시만 제거하지 않는다.
전체 품질 검사의 측정 가능한 geometry 결함을 fit 대상 수집에 연결하고, 내용·의미 문제와 분리한다.
한정된 탐색의 실패는 공간적으로 해결 불가능하다는 뜻이 아니며, 지원 범위/정책 한계로 기록한다.

## 5. 충돌 감지와 공간 배분

### 5.1 감지

기존 `_regions()`의 카드 내부 trailing overflow/flow conflict 감지에 형제 및 고정 band 충돌 seed를 더한다.
seed에는 대상·가리는 요소 QID, 측정 방식, 교차 범위, 의도적 겹침 여부, 해당 root를 기록한다.
DOM 품질 검사의 기존 센서와 분류를 공유한다. 새 판정기를 별도로 복제하지 않는다.
브라우저 탐색에서 완전히 공유하기 어려운 판정은 기존 최초 관찰의 issue를 후보 탐색에 전달하고,
최종 독립 관찰의 품질 판정을 권위로 유지한다. 전달을 위해 새로운 검증 후 복구 루프를 만들지 않는다.

배경이 투명한 부모 전체 bbox만으로 글자가 가렸다고 확정하지 않는다. 실제 텍스트 조각,
페인트/테두리 위치 및 측정 증거를 확인한다. 불확실한 항목은 검토 표시로 남기며 강제로 정상 처리하지 않는다.
의도적 겹침을 자동으로 해제하거나 새로 intentional 표시를 붙이지 않는다.

### 5.2 공간 계산

root는 보호 경계 안의 영향 범위를 한 번 선택한다. 각 seed에서 최대 4개 부모 링크를 확인한다.
같은 가로 영역을 점유하는 다음 요소, 부모의 사용 가능 하단, 보호 푸터 상단을 함께 고려한다.

```text
safe_bottom = min(부모 사용 가능 하단, 보호 푸터 상단, 이동 불가 후행 요소 상단)
available_growth = max(0, safe_bottom - 대상 하단 - 필요한 간격)
required_growth = 실제 폰트·폭에서 필요한 높이 - 현재 사용 가능 높이
```

후행 요소도 옮기는 경우 그 요소와 후속 간격을 같은 영향 영역에 포함하고 전체 필요한 높이를 다시 계산한다.
중첩 padding/gap에서 얻는 공간을 중복 계산하지 않는다. 산술 결과는 후보 생성 근거이며 최종 통과 증거는 아니다.
페이지 아래가 비어 있어도 root 바깥이면 직접 소비하지 않는다. 보호 경계 안의 더 넓은 고정 영역을
처음부터 선택할 수 있는지 확인한다. 문서 전체 높이·viewport 확대는 허용하지 않는다.

### 5.3 초기 지원 구조

| 패턴 | 허용 변경 | 필수 보존 |
| --- | --- | --- |
| 같은 부모의 일정 막대 충돌 | 막대의 세로 위치와 필요한 행 높이 조정, 후행 행/게이트를 같은 범위에서 이동 | x·width·축 매핑·기간·문자열 유지. 일정 관계를 확인할 수 없으면 미지원 |
| 고정 높이 grid 카드 + bottom 고정 설명 박스 | 고정 박스의 높이·간격을 예약한 본문 공간 배분. 같은 행 높이, 관련 간격과 글자 후보 결합 | 열 수·가로 배치·읽기 순서·카드 간 관계 유지 |
| 본문 + 하단 요약 band | 본문 최소 높이와 요약 높이를 함께 산정하여 간격 축소 또는 승인 범위 안에서 요약 y 이동 | 보호 푸터/번호 고정, 내용 및 구분선 관계 유지 |

일반 absolute를 모두 허용하지 않는다. 회전/scale/zoom 없는 측정 가능한 컨테이너, 알려진 containing block,
고정된 외부 bbox를 가진 경우만 후보를 만든다. 14페이지의 절대 위치 body wrapper는 위치를 바꾸지 않고
내부 영향 영역의 고정 경계로만 사용할 수 있도록 지원한다. 이는 기존 absolute/root 배제의 제한적 확장이다.
서버 헤더/푸터는 계속 잠그고, 본문이라는 이유만으로 해당 하위 요소 전부를 수정 가능하게 만들지 않는다.
이미지·차트의 종횡비나 connector 관계를 다시 해석해야 하는 구조는 초기 지원에서 제외한다.

## 6. 후보 탐색과 원자성

기존 `_fitParentRegion()`은 후보 평가와 확정을 동시에 하고 `_restoreParentBase()`로 이전 임시 결과도 지운다.
호출 순서만 앞당기지 말고 plan 생성, snapshot, 평가, restore, 최종 commit을 분리한다.
겹치는 영향 영역은 가능한 경우 하나로 묶고, 선택한 원본 기준에서 한 번 평가한다. 폰트 group/run identity는 고정한다.

초기 후보 집합은 공간만 사용, 가벼운 간격 조정, 기존 폰트 배율(0.975/0.95/0.925/0.90),
기존 간격 후보, 필요한 공간+간격+폰트 조합으로 제한한다. 모든 배율의 무제한 곱집합은 만들지 않는다.
공간 후보는 필요한 높이로 산정하며 임의의 1px 반복 탐색은 하지 않는다. 선언이 같은 후보는 제거한다.

폰트 축소 결과가 먼저 통과해도 공간 후보가 비교에서 빠지지 않게 한다. 기존 비용식
`0.60*T + 0.30*S + 0.10*D`를 공통 기준으로 확장하되 T/S/D는 모두 동일 원본 대비 측정한다.
D는 같은 고정 root 기준의 최대 세로 이동 및 높이 변화 중 큰 값으로 정의한다.
동률은 글자 축소가 작은 후보, 변경 속성이 적은 후보, 고정 후보 순서로 해소한다.
공간 활용을 위해 배치가 크게 바뀌거나 간격을 과도하게 줄이는 후보가 항상 우선하는 것은 아니다.
비용식은 후보 선택 제안이며 미적 최적해를 보장하지 않는다.

최소 간격 2px, 기존 6초/160회 관찰/16개 seed 예산 및 독립 검증 시간 예약을 유지한다.
기존 높이 증가·이동 상한은 초기 보존 검사로 유지하고, 저장 사례에서 그 상한 때문에 탈락하면 실제 필요량을
기록해 별도 설계 조정 대상으로 삼는다. 성공할 때까지 상한을 자동 확대하지 않는다.
비교 예산이 끝나면 제한된 탐색 결과임을 기록한다. 부분 비교를 최적화 완료로 보고하지 않는다.

최종 후보는 영향 범위의 대상 결함을 해소하고, 새 겹침/잘림/화면 이탈 없이 외부 bbox·내용·폰트를 보존해야 한다.
다른 독립 영역이 미해결이면 페이지 전체 변경을 원복하는 현재 계약을 유지한다.
원복 가능한 시각 결함과 폰트/내용/증거 무결성 실패는 구분하며, 후자는 경고로 낮추지 않는다.
기존 허용된 경고 게시 사유만 유지하고 신규 내부 사유는 기존 public 오류와 구분하여 연결한다.

단일 파일 500줄 제한을 지키기 위한 작은 helper 추출은 가능하되 별도 보정 엔진/큐/재시도 체계를 만들지 않는다.
기존 v1.3 결과를 v1.4로 라벨만 바꿔 재사용하지 않는다. 새 정책의 render/acceptance key를 사용한다.
기존 게시물은 과거 정책의 결과로 유지한다. 과거 export/receipt가 현재 상수 변경만으로 거절되지 않도록
정책 revision별 해석을 유지하고, 새 정책으로 재검증하는 경로는 명시적으로 분리한다.

후보별 issue/QID, 실제 적용 폰트 배율, 하한 clamp 여부, 공간 필요량/가용량, 거절 이유,
선택 비용과 변경 속성을 기록한다. 특히 `parent_region_unavailable`에 부모별 제외 조건을 덧붙여
grid 미지원·absolute 경계·보호 경계·깊이 제한을 구분한다. 최종 안내는 페이지·조치·남은 이유만 표시한다.

## 8. 구현 순서와 완료 판정

1. 9pt 정책 및 소비 경계 정렬, 과거 정책/새 정책의 receipt 구분.
2. 카드 내부 넘침 외의 측정 가능한 겹침 seed 연결, 후보 평가와 확정 분리.
3. 확인된 세 가지 구조의 공간 후보 추가 및 기존 축소 후보와 비교.
4. 승인 전 전체 검사와 fit-disabled 재현 검사 연결, 원복/경고 흐름 확인.

구현 완료 뒤 가장 작은 하나의 검증 단위로 저장된 7·14·16페이지와 정상 대조 페이지를 재생한다.
실제 제품 local-fit 진입점을 쓰며, 기존 전역 글자 축소 replay 결과로 대체하지 않는다.
같은 검증 안에서 원본 baseline의 9pt/10% 경계, 후보 간 원복, 다른 영역 보존을 확인한다.
새 테스트 체계를 만들거나 전체 테스트·빌드·20장 생성으로 검증을 넓히지 않는다.

| 대상 | 완료 판정 |
| --- | --- |
| 7페이지 | 겹침 후보가 실제 생성되고 일정 x/width를 보존한 상태로 가림 해소 |
| 14페이지 | 부모 선택 실패 원인이 해소되거나 구체적으로 보고됨. 보안/조직도 충돌을 모두 평가하며 9pt/10% 준수 |
| 16페이지 | 기존 패딩 보정과 별개 band 충돌을 함께 평가. 실제 페인트 충돌과 투명 bbox 교차 구분 |
| 정상 대조군 | HTML 바이트 동일, 불필요한 보정 없음 |
| 공통 | 새 결함 없음, 문자열/QID/자산 보존, 최종 HTML·PNG·측정값 일치, 추가 저작 provider 호출 0회 |

세 페이지 모두의 복구 성공은 검증 목표이지 현재 보장된 결과가 아니다. 미지원·공간 부족·예산 부족은 정확히 보고한다.
PPTX readback의 결과를 DOM 통과로 대신 주장하지 않는다. 최초 설계 단계에서는 테스트·렌더·내보내기를 실행하지 않았다.

## 9. 구현 및 제한된 검증 결과

2026-09-09 멀티 에이전트 구현을 통합했다. 현재 정책은 v1.4 / 9pt이며 원저작 대비 최대 10% 축소를 유지한다.
v1.3 게시물은 기존 9.5pt 정책으로 해석한다. 글자 축소는 결함 텍스트의 원래 서식 그룹에 한정한다.
공간·간격·폰트 후보를 가역적으로 비교하며, 승인 전 전체 geometry 검사와 변경본의 독립 fit-disabled 검증을 연결했다.
첫 후보의 폰트·baseline·증거 오류는 원본 복원 경로에서도 경고로 낮추지 않는다.

제품 렌더/승인 진입점을 사용하는 저장 페이지 4장 재생을 한 검증 단위로 실행했다.
같은 grid 행의 높이 요청 덮어쓰기 버그와 하단 밴드 식별을 수정한 뒤 같은 검증 단위만 한 번 재실행했다.
최종 결과는 다음과 같다.

| 대상 | 실제 결과 | 남은 제한 |
| --- | --- | --- |
| 7페이지 | 하단 반복 라벨과 동반 패널을 함께 압축해 필요한 높이만 이전하고 일정 막대를 두 행으로 분리. 독립 재현 검증과 최종 blocking geometry 0 확인 | 반복 라벨의 의미·대비·내용과 막대 x/width 및 외부 root를 보존하는 범위에서만 적용 |
| 14페이지 | 조직도·보안 충돌을 함께 평가, 원본 보존, 경고 유지 | 공간+간격+폰트 후보는 필요 증가량 29.172px/가용 31.172px까지 도달했으나 배치 보존 검사에서 거절됨. 구체적인 QID/축별 보존 실패 원인은 이번 검증에서 확인하지 못함 |
| 16페이지 | 간격 조정 승인, 독립 재현 검증 통과, 최종 blocking geometry 0 | 수정 전 체크포인트 projection으로 새 baseline을 수집한 검증이며 과거 원저작 raw HTML의 동일 바이트 재현은 아님 |
| 정상 대조 페이지 | HTML 바이트 동일, 변경 작업 0, blocking geometry 0 | 첫 페이지 체크포인트 projection을 사용함 |

9pt 하한, 원본 10% 축소 경계, v1.3 9.5pt 해석 및 승인된 모든 run의 폰트 계약을 같은 검증 안에서 확인했다.
7페이지의 최종 승인 결과에는 글자 크기 변경이 없었고 전체 run의 최소 글자는 9.5pt였다.
따라서 9pt 축소 허용 경계는 검증했지만 실제 9pt 적용 PPTX의 성공을 주장하지 않는다.
추가 저작 provider 호출은 없었다. 기존 PPTX를 수정하거나 다시 생성·게시하지 않았다.
7페이지와 16페이지의 복구를 확인했으며 14페이지는 아직 원본 보존 경고 상태다.
14페이지의 배치 보존 실패 세분화가 후속 대상이다.

7페이지 범용 보정은 특정 클래스·QID·문구에 의존하지 않는다. 동일 장식의 반복 라벨이 여러 행으로 감기고,
같은 donor 행의 단순 텍스트 패널까지 함께 줄일 수 있을 때 후보를 만든다. 상태·범례·선택 의미가 있거나
변환 후 대비가 4.5 미만인 요소는 제외한다. 실제 donor 행 높이 차이 중 필요한 양만 receiver에 이전하고,
변환 영역 내부의 읽기 순서·텍스트 간격·내용 경계와 외부 geometry를 모두 검사한다.

`compiled-spec-memory` 자동 기록은 필수 PowerShell 7 실행 파일이 없어 수행하지 못했다.
사용자의 9pt 허용 결정과 이번 확인 범위는 이 문서에 기록한다.
