## 편집 후 재검토

정상 `quality.review`의 기존 1회 호출·재시도 0회 한도 안에서 변경 페이지의 세부 디자인과 전체 덱의 흐름을 함께 평가한다. 기존 일반 advisory를 새 디자인 판정으로 승격하지 않는다.

신규 생성은 페이지별 정확한 입력·원본·SVG·PNG·native 객체·자산·스타일·폰트·리뷰 도구·런타임 증거를 저장한다. 변경 없는 증거는 같은 소유자·테넌트와 현재 조건에서 정확히 일치할 때만 재사용한다. 재사용할 수 없는 페이지와 명시적 재검토 대상의 합이 5장을 넘으면 제공자 호출 전에 차단한다.

원 생성 작업의 닫힌 리비전과 현재 검토 작업의 리비전을 따로 연결한다. 제공자 호출 후에는 변경 페이지를 포함한 모든 페이지의 입력 해시·원본 manifest·리비전·현재 소유권과 작업 fence를 다시 확인한다. 같은 SVG라도 native·자산 메타데이터가 달라졌으면 이전 판정을 게시하지 않는다.

새 5축 판정의 source-SVG/PNG 디자인 증거는 기존 promptVersion과 호환되게 연결했다. 실제 native OOXML, 최종 PPTX와 원본의 시각적 일치·편집성 검사는 별도로 유지한다.

## 비공개 복구 후보의 권한

실제 고객 SVG를 공유 스타일에 넣더라도 다른 사용자 요청으로 원문이 넘어가지 않도록, 복사·선택·PNG 읽기 전에 현재 정상 소유자·테넌트와 허용된 원본 참조를 확인한다. 실제 성공한 내보내기·닫힌 원본 작업·불변 SVG 체크포인트·SVG/PNG/PPTX 아티팩트와 바이트에서 권한 근거를 재구성한다. 후보의 자체 선언을 권한 증거로 복사하지 않는다.

비공개 자료 경로는 공개 preview/reference 별칭으로 제공할 수 없게 차단한다. 일반 작성 프롬프트에는 후보 원문과 비공개 출처·권한 메타데이터를 포함하지 않는다. 화면 복구에서 실제 선택된 SVG·PNG만 명시적 이전 결과 입력으로 전달한다.

실제로 확인한 내용·native·이미지 구성원·설명 그룹 범위만 적합 범위로 인정한다. 같은 글자 수라는 이유로 다른 내용을 검증했다고 선언하지 않는다. 실제 source text에 없는 표·차트 요구를 과거 OOXML 구조만 보고 만들어 내지 않는다. 과거 리비전의 불변 참조가 없으면 현재 리비전을 대신 사용하지 않는다.

## 실제 수용 검증의 조건

현재 로컬 서버의 `/auth/verify`는 인증이 꺼진 상태의 `method=local`을 반환한다. 일반 GET이 성공했다는 사실은 정상 소유자·테넌트 증명이 아니다. 기존 인증이 켜진 검증 서버 또는 기존 정상 계정의 인증 파일 경로를 사용자에게 요청했다. 인증 설정이나 자격 증명을 임의로 변경하지 않는다.

실제 복구 후보 등록은 0개다. 후보로 조사한 과거 자료는 소유권·불변 리비전·현재 실행 조건·내용 적합성·native·시각 품질을 모두 확인한 뒤에만 등록할 수 있다. 정상 인증 문맥이 확보되면 같은 조건의 12장 비교를 먼저 진행하고, A4·긴 덱에서 원본·캡처·편집성·최종 완료 시간과 호출·토큰을 확인한다. 아직 실제 제공자 생성·편집 재검토·새 PPTX/Office 검증이나 속도 개선을 완료했다고 판정하지 않는다.

로컬 코드 반영은 별도의 관리 상태·실행 중 작업 확인을 거쳐 수행하며, 인증 설정·포트·PostgreSQL·Next.js·proxy를 유지하고 영향받은 백엔드 구성 요소만 재시작한다. 원본 미추적 설계·인계 문서는 named backup에 바이트 해시를 확인해 보존한다.
