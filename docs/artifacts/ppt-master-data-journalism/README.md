## 제안 메시지

1. 2025년 민간 AI 투자는 최고점을 갱신했고 생성형 AI가 자금의 절반에 가까워졌다.
2. 미국은 민간 투자와 신규 기업 수에서 압도적 우위를 유지한다.
3. 자본은 서버·데이터센터·전력망을 거쳐 업무 도입과 경제적 가치로 전환된다.
4. 공급자 매출과 빅테크 CapEx는 이 전환이 이미 물리 인프라 단계에 도달했음을 보여준다.
5. 다음 병목은 모델만이 아니라 전력, 계통, 인허가와 도입 실행력이다.
