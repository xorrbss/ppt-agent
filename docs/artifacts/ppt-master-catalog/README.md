# PPT Master template catalog

This development catalog contains five editable PowerPoint templates derived from the approved PPT Master visual direction:

- Executive report
- Business proposal
- Data analysis report
- AI technology proposal
- Project performance report

Each PPTX contains 15 reusable core layouts. The deck length is not fixed: users can duplicate, delete, and reorder slides to fit the presentation. All figures and organization names are illustrative sample data and should be replaced before external use.

The Next.js template selection screen exposes these files only in local development. Production catalog registration and generation-service integration remain gated on the repository's rights/provenance approval process.
