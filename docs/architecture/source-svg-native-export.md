# 원본 SVG의 편집형 내보내기 계약

## 확인된 동작

- `svg-source-whole-page/v1`의 편집형 PPTX는 `public-svg-export-bundle/v4`로 전달한다. 서버가 확인한 원본 manifest, 소유 범위, 페이지 순서, SVG digest와 내보내기 검증 코드 digest를 함께 결합한다.
- 내보내기 전용 어댑터는 원본 SVG와 생성 시 승인된 converter를 수정하지 않는다. 임시 변환 hook은 단일 작업 프로세스에서만 사용하고 종료 전에 복원한다.
- 차트 범주와 데이터 값은 native 차트와 내장 통합 문서가 소유한다. 정적 숫자 복사본으로 native 표시 검증을 대체하지 않는다. 실제 수식, 캐시, 점 색인, 표시 설정, 글꼴과 색을 읽어 확인한다.
- 제목과 단위는 원본 바인딩이 있는 편집 도형으로 보존한다. 위치 지정 본문 tspan은 페이지·원본 ID·줄 색인, 내용, 서식과 승인된 좌표 변환에 따라 검증한다. 증명되지 않은 분절은 거부한다.
- 표 숫자는 명시적인 원본 `text-anchor=end`와 실제 셀 소유가 확인될 때만 오른쪽 정렬로 투영한다. 헤더 가운데 정렬을 추정하지 않는다.
- 차트 격자선 색은 원본 plot의 균일한 불투명 stroke에서만 얻는다. native 격자선의 고정 선폭을 원본 선폭 보존으로 표현하지 않는다.
- 글꼴 임베딩은 마지막 저장 후 허용된 bundled font로 수행한다. ZIP part 중복, 추가 part, 관계, 글꼴 바이트와 비글꼴 part 보존을 확인한다.
- 최종 PPTX의 도형 타입·기하·관계를 변환 추적과 대조한다. 단일 자식 그룹의 평탄화 별칭은 원본 계보와 반환 XML이 일치할 때만 허용한다. source/style readback과 최종 파일 digest를 품질 영수증의 OOXML 증거에 결합한다.

## 증거의 경계

원본 SVG의 브라우저 측정, 최종 OOXML 검사, 실제 PowerPoint 읽기와 렌더 확인은 서로 다른 증거다. OOXML 통과로 Office 시각 검사를 통과했다고 기록하지 않는다. 기존 정상 API의 SVG visual advisory는 Office 이미지 등록 경로를 제공하지 않으므로, Office 확인 결과로 해당 영수증을 수동 변경하지 않는다.

`interactive-v1` 내보내기 성공과 `releaseReadiness=ready`는 별개다. 필요한 advisory가 없으면 `visualReview`와 release 상태를 그대로 유지한다. 인증이 비활성인 로컬 API 확인을 인증된 환경의 수락 검증으로 확대하지 않는다.

## 비용과 이력

승인된 캐시 복구는 원본 author 결과만 사용하고 새 제공자 호출·비용·예약 한도를 0으로 묶는다. 원본과 실패한 중간 작업의 이력은 변경하지 않는다. 정상 내보내기 요청은 기존 권한·소유·revision 검증을 통과해야 하며, 불명확한 디스패치를 자동 재전송하지 않는다.
